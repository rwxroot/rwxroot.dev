# rwxroot.dev
Minimal, terminal-themed portfolio built with [Zola](https://www.getzola.org/)

## Build

```sh
zola build
```

## Serve
With [static-web-server](https://static-web-server.net/), config in this repo:

```sh
static-web-server --config-file /home/rwxroot/Work/code/rwxroot.dev/sws.toml
```
